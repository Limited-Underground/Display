# ECLU Working-Name Review

Status: provisional working name, screened 2026-08-10

This is a point-in-time naming screen, not a legal clearance opinion. OpenTrail
and OpenGauge remain the repository and technical project names. `ECLU` is only
a candidate umbrella name under Limited Underground while the name is evaluated.

## Current decision

Risk is **yellow / moderate**. `ECLU` remains reasonable as a reversible working
name for design and testing, especially for a United States-first open-source
project, but it is not clean enough to treat as a cleared worldwide brand.

Before paid promotion, printed enclosures, hardware markings, merchandise, or a
formal product launch, obtain a professional clearance search covering at least
the likely electronics/software, telecommunications, and software-service
classes and the intended countries. That review should include confusingly
similar spellings and unregistered market use, not just exact federal records.

## Reversible-name boundary

- Do not rename the OpenTrail or OpenGauge repositories yet.
- Do not put `ECLU` into packet magic, protocol namespaces, persistent schemas,
  key domains, device identities, or hardware identifiers.
- Keep the eventual human-facing brand in one presentation configuration value
  per application so a later name change does not alter compatibility.
- Use neutral technical component names in firmware and tools.
- Recheck registries, domains, and developer namespaces immediately before any
  filing or public launch because this screen is date-sensitive.
