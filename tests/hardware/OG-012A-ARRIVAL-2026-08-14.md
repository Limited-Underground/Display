`303A:1001`. After the owner disconnected one unit, the count changed to one.
The public interface description was `USB Serial Device`, the manufacturer was
`Microsoft`, and the state was `Started`.

This count change is consistent with both owner-reported units presenting the
same public USB interface. It is not a stable device identity, board-revision
result, or package-to-unit binding.
