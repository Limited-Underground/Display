# OG-018H External Host-Mediated Alert/ACK Wire Evidence

Date: 2026-08-09

Status: passed as an external interoperability observation against OpenGauge's
public normative `OGA0` fixture. This is not OpenGauge firmware, authenticated
transport, outbox/ACK-ingress execution on hardware, or a supported radio.

## Evidence source and boundary

OpenTrail commit `62022c7` added the reproducible
`Test-MeshCoreCriticalAlertAck.py` harness and full OT-017D record. The harness
loaded OpenGauge's public normative `engine_over_temperature_asserted` fixture,
sent its exact 64 bytes through one Heltec MeshCore USB Companion, processed it
with OpenTrail's real host ingress/responder, sent the correlated 64-byte
`OGK0` response through the other Heltec, and decoded every ACK field. It then
repeated with the Heltec roles reversed while observing a SenseCAP repeater.

OpenGauge's independent exporter and ACK codec continue to validate the same
normative bytes in deterministic host tests. The physical harness did not run
the OpenGauge exporter, outbox, ACK ingress, negative policy, or checkpoint
store on a device, so those are not physical claims.

## Observed result

- 2/2 exact 64-byte `OGA0` alerts delivered;
- 2/2 correlated 64-byte `OGK0` ACKs delivered;
- every accepted/reason, producer, consumer, event, condition, lifecycle,
  boot-session, sequence, and observed-age check passed;
- zero alert/ACK loss, duplicates, new endpoint errors, or repeater errors;
- host-observed round trips of 1009.6 and 1014.0 ms;
- SenseCAP exact aggregate +4 flood RX and +4 flood TX, with repeat staying on;
- 4/4 endpoint channel-cleanup checks passed and both lease journals were
  removed;
- the temporary channel secret remained in memory and was never printed or
  persisted.

## Remaining gates

  physical loop rather than loading a fixture and decoding on the OpenTrail
  host.
- Authenticate and authorize the application peer/session rather than having
  the host supply that trust context.
- Bind authorization, ACK checkpoint, outbox state, and secure rollback to

- Replace MeshCore text/base64 with a selected on-device transport adapter.
